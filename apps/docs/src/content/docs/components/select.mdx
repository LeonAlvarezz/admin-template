## Import

```tsx
import { Select } from "@z3/admin-core";
```

## Props Reference

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `options` | `SelectOption[]` | `[]` | Array of options, groups, or strings |
| `searchable` | `boolean` | `false` | Enables client-side combobox search |
| `multiple` | `boolean` | `false` | Enables multi-select tag chips |
| `clearable` | `boolean` | `false` | Displays a clear button (`x`) |
| `loadOptions` | `(query) => Promise` | `undefined` | Async remote data fetcher |
| `debounceMs` | `number` | `250` | Debounce delay for async search |
| `loading` | `boolean` | `false` | Displays a loading spinner |
