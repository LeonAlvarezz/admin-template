
## Props Reference

| Prop        | Type                                                                              | Default     | Description                                   |
| :---------- | :-------------------------------------------------------------------------------- | :---------- | :-------------------------------------------- |
| `variant`   | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "barebone"` | `"default"` | Visual appearance variant                     |
| `size`      | `"icon" \| "sm" \| "base" \| "md" \| "lg" \| "xl"`                                | `"base"`    | Button height and padding size                |
| `loading`   | `boolean`                                                                         | `false`     | Shows an animated spinner and disables clicks |
| `disabled`  | `boolean`                                                                         | `false`     | Disables interaction and dims opacity         |
| `className` | `string`                                                                          | `undefined` | Additional Tailwind CSS classes               |
