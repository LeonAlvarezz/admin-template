`Input` and `InputPassword` wrap native text inputs with consistent focus rings, leading/trailing icon slots, and show/hide password buttons.

## Import

```tsx
import { Input, InputPassword } from "@z3/admin-core";
```

## Props Reference

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `startIcon` | `ReactNode` | `undefined` | Leading icon element |
| `endIcon` | `ReactNode` | `undefined` | Trailing icon element |
| `invalid` | `boolean` | `false` | Applies error border and ring |
| `containerClassName` | `string` | `undefined` | Classes for outer wrapper `div` |
