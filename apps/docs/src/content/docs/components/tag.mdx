## Import

```tsx
import { Tag } from "@z3/admin-core";
```

## Props Reference

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `Color` (Tailwind palette) | `"blue"` | Tailwind color variant (`violet`, `emerald`, `amber`, etc.) |
| `showDot` | `boolean` | `false` | Displays a leading pulse dot indicator |
| `size` | `"sm" \| "md"` | `"md"` | Tag padding and font size |
