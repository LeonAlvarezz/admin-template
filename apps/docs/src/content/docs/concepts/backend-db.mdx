`apps/backend` follows a clean **Controller / Service / Repository** architecture built on **Express 5** and **Drizzle ORM**.

## Architecture Layers

```
apps/backend/src/
├── config/                # Environment variables, CORS, and OpenAPI spec
├── core/                  # Middleware (auth guard, error handling, envelope wrapper)
├── db/
│   ├── schema/            # Drizzle ORM schemas (user, product, order, session)
│   ├── migrations/        # SQL migration files generated by Drizzle Kit
│   └── seed.ts            # Default seed data script
└── modules/               # Domain feature modules (Controller, Service, Repository, Route)
    ├── auth/
    ├── user/
    ├── product/
    └── order/
```

## Database Management Commands

Run database commands from the repository root:

```bash
# Start PostgreSQL 16 container
bun docker:up

# Run migrations
bun db:migrate

# Seed default admin accounts
bun db:seed

# Inspect database with Drizzle Studio
bun --cwd apps/backend studio

# Reset database (drops all tables)
bun db:reset
```

## Interactive Scalar API Docs

When running the backend (`bun run dev:backend`), open:
👉 **[http://localhost:3333/docs](http://localhost:3333/docs)**
