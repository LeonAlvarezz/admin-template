## Option 1: Scaffolding CLI (Recommended)

Generate a new project with your choice of **Mock Data (Frontend Only)** or **Fullstack Monorepo**:

<Tabs>
  <TabItem label="bun">
```bash
bun create-z3-admin my-admin
cd my-admin
bun install
bun run dev
```
  </TabItem>
  <TabItem label="npm">
```bash
npx create-z3-admin my-admin
cd my-admin
npm install
npm run dev
```
  </TabItem>
  <TabItem label="pnpm">
```bash
pnpm create-z3-admin my-admin
cd my-admin
pnpm install
pnpm run dev
```
  </TabItem>
<TabItem label="yarn">
```bash
yarn create-z3-admin my-admin
cd my-admin
yarn install
yarn dev
```
</TabItem>
</Tabs>

## Option 2: Clone & Interactive Setup Wizard

```bash
# 1. Clone repository
git clone https://github.com/LeonAlvarezz/admin-template.git my-admin
cd my-admin
bun install

# 2. Run interactive setup wizard
bun run setup
```

The setup wizard will ask if you want to run with **Mock Data**, **Fullstack**, or permanently **Strip the Backend**.

---

## Option 3: Manual Execution

Standalone Frontend (Mock Data)
```bash
cp apps/starter/.env.example apps/starter/.env
# Set VITE_ENABLE_MOCK=true in apps/starter/.env
bun run dev:mock
```

### Fullstack Mode
```bash
cp apps/backend/.env.example apps/backend/.env
cp apps/starter/.env.example apps/starter/.env

# Start database and apply migrations
bun docker:up
bun db:migrate
bun db:seed

# Run full stack in parallel
bun run dev
```
